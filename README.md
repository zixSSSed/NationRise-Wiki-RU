# NationRise — вики, зеркало на .ru

Копия вики, размещённая на **GitHub Pages** и привязанная к домену
**wiki.nationrise.ru**.

Основная площадка — [wiki.nationrise.space](https://wiki.nationrise.space),
репозиторий [NationRise-Wiki](https://github.com/zixSSSed/NationRise-Wiki).

## Зачем

Запасной вход для игроков, у которых не открывается основной домен.
Содержимое то же самое, отличаются только `docs/CNAME` и `site_url`
в `mkdocs.yml`.

## Обновление

После правок в основном репозитории скопировать сюда папку `docs`
(кроме `docs/CNAME`) и закоммитить — GitHub соберёт сайт сам.
